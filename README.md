# 🕹️ Awesome Tic-Tac-Toe

A sleek, interactive **Tic-Tac-Toe game** built using **HTML**, **CSS**, and **Vanilla JavaScript**. Designed for two players, it features responsive UI, real-time player switching, winner detection, and a new game reset button.

## ✨ Features

- 🎯 **Player Turn Tracking** – Shows current player (X or O).
- 🧠 **Winner Detection** – Automatically detects winning combinations.
- 🖍️ **Winning Highlight** – Highlights the boxes that form the winning line.
- 🚫 **Click Prevention** – Blocks interaction on already-filled or completed games.
- 🔄 **Game Reset** – "New Game" button resets the board and starts fresh.
- 💡 **Draw Condition** – Declares "Game Tied!" when all boxes are filled without a winner.
- 💻 **Responsive Layout** – Simple and adaptable layout for all screen sizes.
- 🎨 **Custom Fonts** – Integrated with Google Fonts (Poppins) for a modern look.
